# DesktopIconFixer

起因很简单:某天我桌面上的抖音图标没了。查了一圈发现程序还在,快捷方式文件也还在,是 Windows 的图标缓存坏了。修完顺手把过程写成脚本,后来又加上了失效快捷方式的自动修复,就成了这个工具。

## 它修什么

桌面图标出问题,十有八九是这两种情况:

**图标缓存坏了。** 程序好好的,快捷方式也指着正确的地方,但图标就是一片空白。这是 Windows 自己的渲染缓存出了问题,删掉缓存文件、重启资源管理器就好。

**快捷方式指错了地方。** 软件升级经常换目录,比如从 `D:\App\XXX\7.0.0\` 挪到 `7.1.0\`,旧快捷方式还指着老路径。脚本会沿着旧路径附近找同名 exe——开始菜单、注册表卸载信息、常见安装目录也都翻一遍——找到就把快捷方式指过去,顺便把图标换成程序自带的。

## 用法

双击 `一键修复桌面图标.bat`,没了。

想先看看它打算干什么再动手,加个 `-ScanOnly`,只诊断不改任何东西:

```bat
一键修复桌面图标.bat -ScanOnly
```

直接跑 PowerShell 脚本也一样:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File Fix-DesktopIcons.ps1
```

## 几件要知道的事

- 跑完最后会重启 explorer,桌面和任务栏闪一下,正常现象,已打开的窗口不受影响。
- 有两类情况它不会自动修,只会在报告里列出来:软件已经卸载的,和软件升级后改名换主程序的(比如 Cisco AnyConnect 升级成 Secure Client 后,`vpnui.exe` 变成了 `csc_ui.exe`)。不猜是因为注册表里的图标信息经常指向卸载器之类的程序,瞎指不如不指,这种情况人工确认一下更稳。
- "此电脑"、UWP 应用这类系统对象会自动跳过,不用管。
- 搜新目标时有深度限制(从旧路径往上翻 4 层目录,每层往下递归 4 层),不会全盘扫,一般几十秒内跑完。

Windows 10/11 都能用,PowerShell 用系统自带的 5.1 就行,不用装任何东西。
